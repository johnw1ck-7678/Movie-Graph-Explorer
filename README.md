# Graph Database Web Application

A full-stack **Graph Database Web Application** built using **Node.js, Express.js, JavaScript, Cypher, and CognoDB Cloud**.
Minimal frontend with **critical backend** and **graph database.**

The project demonstrates how connected data can be represented, queried, and explored using a graph database, with movies and people connected through meaningful relationships.

## Project Overview

The application contains:

- **28 Movies**
- **48 Persons**
- Connected movie-person relationships
- Interactive graph data exploration
- Cypher-based graph queries
- REST API backend
- CognoDB Cloud as the graph database
- Web-based interface for interacting with the graph

## Graph Structure

The database represents relationships between people and movies.

```text
Person ── ACTED_IN ──> Movie
Person ── DIRECTED ──> Movie
```
